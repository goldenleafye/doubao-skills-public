# 国风电影光影风格转换

## 触发条件

当用户提供一张或多张图片，并要求：
- 把照片改成国风/古风/汉服风格
- 转换成电影感、光影大片风格
- 分析图片风格并应用到其他图片
- 提到"国风光影""汉服写真""丁达尔光""青橙调"等

## 风格定义（必须严格遵循）

### 核心视觉特征

1. **光影**
   - 强烈的方向性光束（丁达尔效应/God rays），从画面一侧或上方斜射
   - 树叶/窗棂投影在人物面部、身体和衣物上形成斑驳光斑
   - 明暗对比强烈（chiaroscuro），暗部深沉但不死黑
   - 逆光/侧逆光勾勒人物轮廓，形成发丝光和衣物透光感
   - 光束中有可见的微尘/雾气粒子

2. **色调（青橙调 Teal & Orange）**
   - 暗部/阴影：深青蓝、墨绿、冷灰
   - 亮部/高光：暖琥珀、金黄、蜜橘色
   - 整体低饱和、高级灰调，肤色偏暖白
   - 红色元素（灯笼、红叶、唇色）作为点缀色，饱和度略高
   - 色彩过渡柔和，有胶片色彩分离感

3. **氛围与质感**
   - 空灵、诗意、静谧、略带忧郁
   - 电影感画面比例和构图
   - 浅景深，背景虚化，前景有虚化的红叶/花枝/烟雾
   - 胶片颗粒感（film grain）
   - 柔和但不过度的锐度，高光有轻微光晕（halation）
   - 空气透视感，远处有薄雾

4. **人物与服饰**
   - 汉服为主：交领、大袖衫、齐胸襦裙、刺绣丝绸
   - 面料有光泽感，在光线下呈现珍珠/丝绸般的反光
   - 发型为古典发髻，配发簪、步摇、珠花
   - 油纸伞、团扇、灯笼等道具
   - 姿态娴静、低眉、回眸、撑伞等古典姿态

5. **环境元素**
   - 古典园林：假山、回廊、花窗、亭台
   - 红灯笼、宫灯（暖光源）
   - 红枫、竹林、垂柳、落花
   - 烟雾/雾气/水汽
   - 老树、石桥、木栏杆

### 风格 Prompt 模板

对用户图片进行风格转换时，使用以下 prompt 结构（根据原图内容调整主体描述）：

```
将这张照片转换为国风电影光影风格：

光影：强烈的丁达尔光束从画面斜射而入，树叶斑驳投影落在人物面部和衣物上，侧逆光勾勒发丝和轮廓，暗部深沉有层次，光束中有微尘浮动。

色调：青橙电影色调，暗部偏深青蓝墨绿，高光偏暖琥珀金黄，整体低饱和高级灰，红色元素（灯笼/红叶/唇色）作为点缀。

质感：电影感浅景深，前景虚化红叶花枝，胶片颗粒感，高光轻微光晕，空气透视薄雾，丝绸面料在光线下有珍珠光泽。

氛围：空灵诗意，静谧忧郁，如古典诗词意境。

[根据原图补充：保留原图人物的面部特征/姿态/构图，将服装替换为汉服/保留原场景但添加古典园林元素等]
```

## 执行流程

### 第一步：分析用户图片

收到用户图片后，先观察并描述：
- 主体是什么（人物/风景/建筑/物体）
- 原图的光线方向和强度
- 原图的构图和色调
- 哪些元素可以保留，哪些需要替换为国风元素

### 第二步：确定转换策略

- **人物照片**：保留人物面部特征和姿态，将服装改为汉服，添加古典光影和环境
- **风景照片**：添加国风元素（亭台、灯笼、竹林、烟雾），调整为青橙色调和电影光影
- **物体/静物**：放置在古典场景中，添加光束和氛围
- **建筑照片**：如果是中式建筑则强化光影氛围；如果是现代建筑则考虑添加古风元素或转换场景

### 第三步：生成风格化图片

使用 `image_edit` 工具（图生图/风格迁移）：
- 将用户原图作为 `image_reference_url_list` 输入
- prompt 使用上述风格模板，结合原图分析结果定制
- 保持原图比例（局部编辑/风格转换必须保持原图比例）
- 一次生成一张，如用户需要可生成多个变体

### 第四步：交付

- 向用户展示生成结果
- 简要说明做了哪些风格化处理
- 询问是否需要调整（如光束更强/更弱、色调更暖/更冷等）

## 注意事项

- 保留人物的面部特征和辨识度，不要改变人物身份
- 风格转换要自然，避免汉服穿帮（如拉链、现代配饰残留）
- 如果原图是多人合照，为每个人物都添加合适的汉服造型
- 光束方向要与原图光源逻辑一致，避免光影矛盾
- 不要过度磨皮，保留胶片质感和皮肤纹理
- 参考图存放在 assets/ 目录，可用于风格对照
