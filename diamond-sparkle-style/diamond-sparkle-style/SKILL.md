# 钻石碎闪风格（Diamond Sparkle Style）
将写实照片转换为物体表面覆盖碎钻/水晶/水钻镶嵌质感的梦幻风格，高光处有十字星芒，画面散布闪粉粒子。
## 风格核心特征
1. **碎钻/水晶表面质感**：画面中主要物体（建筑、植物、衣物、水面、岩石、器物等）表面覆盖密集的碎钻/水晶/水钻镶嵌纹理，呈现多面切割反射效果，像施华洛世奇水晶或碎钻铺满表面
2. **十字星芒高光**：明亮高光点发出4-6条射线的十字星芒（starburst/lens flare），射线清晰锐利
3. **闪粉粒子**：画面中散布细小的白色/银色/金色闪光粒子，漂浮在空气、水面、树叶间
4. **高饱和高对比色调**：深蓝（天空/海洋）、翠绿（植物）、暖金（阳光/高光）为主色调，暗部深沉，亮部耀眼
5. **选择性应用**：不是所有物体都闪，通常主体物和受光面闪，保留部分正常质感形成对比
6. **写实基底**：底层照片保持写实构图和透视，闪钻效果是叠加层，不改变物体轮廓和场景结构
## 工作流程
### 第一步：分析用户图片
收到用户图片后，先观察：
- 图片中的主体物是什么（人物/建筑/自然风景/静物等）
- 光源方向和高光区域
- 哪些物体/表面适合覆盖碎钻效果（受光面、光滑表面、主体物优先）
- 图片整体色调（偏冷/偏暖）
### 第二步：生成风格化图片
使用 `image_edit` 工具，将用户图片作为参考图传入。详细 prompt 模板和参数见 [references/prompt-guide.md](references/prompt-guide.md)。
**基础 prompt 结构**：
```
保持原图构图和内容不变，将画面转换为钻石碎闪风格：[主体物]表面覆盖密集碎钻水晶镶嵌质感，多面切割反射；高光处有锐利十字星芒；画面散布细小闪粉粒子；高饱和度，深蓝翠绿暖金色调，高对比度，暗部深沉亮部耀眼；写实照片基底，梦幻镶钻效果叠加
```
**关键参数**：
- `model_version`: `seedream_4.5`（默认）
- `image_reference_url_list`: 用户图片的 URL（必须）
- `width` / `height`: 保持原图比例
- `prompt`: 按上述结构，根据图片内容具体化
### 第三步：交付与迭代
- 生成后通过 `NotifyHuman` 交付图片
- 如果用户觉得闪钻效果不够/太多，调整 prompt 中碎钻覆盖范围描述
- 如果色调不对，调整色调描述
- 可多次生成让用户选择
## 注意事项
- 必须保持原图的构图、物体轮廓和场景结构不变，只改变表面质感和光影
- 碎钻效果优先应用在受光面和主体物上，不要全图无差别铺满
- 人物面部不要覆盖碎钻（保持面部自然），衣物和配饰可以
- 如果原图有文字，保持文字清晰可读
- 参考素材图片存放在 `assets/` 目录，需要时可读取以确认风格细节
