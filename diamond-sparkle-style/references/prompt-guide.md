## 通用 prompt 模板
### 基础版（适用于大多数照片）
```
保持原图构图、物体轮廓和场景结构完全不变，将画面转换为钻石碎闪风格：画面中主要物体表面覆盖密集的碎钻水晶镶嵌质感，呈现多面切割的璀璨反射；所有高光点发出锐利的十字星芒光芒；画面中散布细小的银色闪粉粒子；整体高饱和度，深蓝翠绿暖金色调，高对比度，暗部深沉亮部耀眼；写实照片基底上叠加梦幻镶钻效果
```
### 加强版（闪钻效果更明显）
```
保持原图构图和内容不变，强烈的钻石碎闪风格：物体表面完全被密集碎钻和水晶覆盖，每颗碎钻都有清晰的多面切割反射和彩虹色散；高光处有强烈的十字星芒和镜头光晕；大量金色和银色闪粉粒子漂浮在整个画面中；极高对比度和饱和度，深邃的蓝色阴影与耀眼的金色高光形成强烈对比；如同整个世界由钻石和水晶构成
```
### 自然版（闪钻效果较含蓄）
```
保持原图构图和内容不变，自然的钻石微光风格：物体受光面和光滑表面带有细腻的碎钻水晶光泽，边缘和高光处有柔和的十字星芒；少量闪粉粒子点缀；保持原图色调基础上略微提升饱和度和对比度；写实为主，碎钻效果作为点缀
```

## 按场景分类的 prompt
### 风景/海景
```
保持原图构图和内容不变，钻石碎闪风格：海面波光覆盖密集碎钻反射，每朵浪花都有水晶般的多面切割光泽；岩石和沙滩受光面覆盖碎钻镶嵌质感；天空云层边缘有闪粉粒子和十字星芒；植物叶片上有细碎钻光；高饱和度深蓝海水与翠绿植物，暖金色阳光高光，高对比度
```
### 建筑/室内
```
保持原图构图和内容不变，钻石碎闪风格：建筑外墙和结构表面覆盖碎钻水晶镶嵌质感，玻璃和金属表面有强烈的多面切割反射；高光处有锐利十字星芒；水面（如有）布满碎钻般的波光；空气中漂浮银色闪粉粒子；高对比度，深邃阴影与璀璨高光
```
### 植物/花卉
```
保持原图构图和内容不变，钻石碎闪风格：植物叶片、花瓣和枝干表面覆盖碎钻水晶质感，叶脉和边缘有细腻的钻光；受光面有强烈的多面切割反射和十字星芒；周围空气中漂浮金色闪粉粒子；高饱和度翠绿与暖金色调，深色背景衬托璀璨高光
```
### 人物
```
保持原图构图、人物姿态和面部特征不变，钻石碎闪风格：人物衣物和配饰覆盖碎钻水晶镶嵌质感，面料上有密集的多面切割反射；头发受光处有细碎钻光和星芒；周围环境物体表面带有碎钻质感；面部保持自然不覆盖碎钻；空气中漂浮银色闪粉粒子；高对比度，暖金色高光
```
### 静物/器物
```
保持原图构图和内容不变，钻石碎闪风格：主体器物表面完全覆盖碎钻水晶镶嵌，每颗碎钻有清晰的多面切割和彩虹反射；高光处有强烈十字星芒；背景和桌面带有细腻的碎钻光泽；大量闪粉粒子漂浮；高饱和度，深色背景突出主体璀璨光芒
```

## 效果强度调节
| 用户反馈 | 调整方式 |
|---------|---------|
| "闪钻不够多/不够闪" | 使用加强版模板，增加"完全覆盖""强烈""大量"等词 |
| "太闪了/太假了" | 使用自然版模板，减少碎钻覆盖范围，强调"受光面""点缀" |
| "颜色不对" | 在 prompt 中明确指定主色调，如"偏冷蓝色调""暖金色调" |
| "星芒太多" | 将"十字星芒"改为"柔和微光"，去掉"镜头光晕" |
| "想要更梦幻" | 增加"彩虹色散""光晕""薄雾""梦幻氛围"等描述 |
| "想要更写实" | 强调"写实照片基底""碎钻效果自然""保持真实质感" |

## 常见问题与修正
### 问题：生成后物体变形/构图改变
- **修正**：在 prompt 开头强调"严格保持原图构图、物体轮廓、透视关系完全不变"
- 确保使用 `image_edit` 而非 `image_gen`
### 问题：碎钻效果覆盖了不该覆盖的区域（如人脸、天空）
- **修正**：在 prompt 中明确排除，如"人物面部保持自然皮肤质感，不覆盖碎钻""天空保持自然云层，仅在高光处有微光"
### 问题：色调偏离原图
- **修正**：在 prompt 中加入"在保持原图色调基础上"或明确指定目标色调
### 问题：图片比例不对
- **修正**：`width` 和 `height` 必须与原图一致，从用户图片元数据获取尺寸
