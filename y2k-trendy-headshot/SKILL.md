# Y2K 潮流大头贴写真

## 触发条件
当用户提供一张人物照片并要求：
- "把这张照片做成潮流大头贴 / Y2K写真 / 千禧风头像"
- "生成一组贴纸风写真 / 大头贴风格头像"
- 提到"Y2K""大头贴""purikura""千禧年""贴纸风头像""潮流儿童写真"等
- 上传一张人像（尤其老照片、日常照）并要求"按这个风格生成一组写真"

## 风格定义（必须严格遵循）

### 核心视觉特征
1. **构图与景别**
   - 1:1 正方形构图
   - 大头特写（headshot / bust），头部居中，画面聚焦面部
   - 人物从肩部以上或胸部以上入镜

2. **背景**
   - 纯白色 / 极浅米白干净背景
   - 无杂物、无环境场景，主体像被"抠"出来置于白底

3. **主体保留**
   - 严格保留原图人物的面部特征（五官、脸型、神态、肤色）
   - 保留原图中标志性的服饰/配饰（如帽子、发饰的颜色与图案）
   - 老照片需重绘为高清精致质感，但人物身份可辨认

4. **画质与质感**
   - 高清数码精致质感，皮肤细腻有光泽
   - 高锐度、高细节，商业写真级画质
   - 部分变体带贴纸白边 cutout 或全息镭射边框

5. **潮流配饰（Y2K 千禧风）**
   - 墨镜（金属框/黑框窄框，可架在头顶或戴在脸上）
   - 耳环（绿松石耳坠等复古款）
   - 头戴式耳机（镭射银/全息透明质感）
   - 水钻牙贴 / 镶钻牙齿（grillz）
   - 帽子上的彩色珠串、星星别针、链条等装饰

6. **装饰元素**
   - 四角星闪光（sparkle stars，十字/四角星芒）
   - 彩虹贴纸
   - 银色立体星星
   - 宝丽来复古细边框 / 白色描边贴纸轮廓 / 透明全息圆角边框

7. **色彩与氛围**
   - 肤色自然暖调，配饰高饱和点缀
   - 整体明亮、干净、通透
   - 氛围：俏皮、潮流、Y2K千禧感、可爱搞怪

### 三个固定变体（每次必须输出 3 张，数量与造型一一对应）

**变体1 —— 复古潮童（墨镜+耳环）**
- 金属框墨镜架在头顶
- 双耳佩戴绿松石复古耳坠
- 面部可加自然小雀斑
- 表情俏皮（抬头望向上方、微张嘴）
- 四角散布暖色星星闪光
- 宝丽来风格细边框（黑边+白边）

**变体2 —— 装饰帽潮童（帽子装饰+牙钻）**
- 保留原图帽子，并在帽上装饰彩色珠串、星星别针、金属链条、彩色圆珠
- 黑色窄框墨镜戴在脸上
- 大笑露齿，牙齿贴满水钻（grillz）
- 人物带白色描边 cutout 贴纸轮廓
- 纯白背景

**变体3 —— 耳机Y2K潮童（镭射耳机+全息边框）**
- 保留原图帽子
- 佩戴镭射银/全息透明质感头戴式耳机
- 周围散布银色立体四角星和彩虹小贴纸
- 透明全息镭射质感圆角方形边框
- 纯白背景

## 执行流程

### 第一步：分析用户图片
- 确认主体为人物，观察面部特征、发型、标志性服饰（尤其帽子/发饰的颜色图案）
- 记录必须保留的身份特征

### 第二步：准备参考图
本技能 assets 目录下有 3 张风格参考图（ref1.jpg / ref2.jpg / ref3.jpg），分别对应三个变体。
- 若 image_edit 需要公网 URL，先用 FileBatchUpload 将 assets 目录下的 ref1~ref3.jpg 上传，获取可访问 URL
- 用户上传的原图同样需要可访问的 URL（附件链接或上传后获取）

### 第三步：生成 3 张风格化写真
使用 **image_edit** 工具，在一次调用的 `request_list` 中放入 **3 个请求**（并行生成 3 张），每个请求：
- `width`: 2048, `height`: 2048（1:1 方形）
- `model_version`: seedream_4.5（默认）
- `image_reference_url_list`: 包含 **[用户原图URL, 对应变体参考图URL]**（变体1配 ref1，变体2配 ref2，变体3配 ref3）
- `prompt`: 使用下方对应变体的 prompt

**变体1 prompt：**
```
将这张人物照片转换为Y2K潮流大头贴风格写真。1:1正方形构图，大头特写，头部居中，纯白色干净背景。严格保留原图人物的面部五官、脸型、神态和标志性帽子/发饰。高清精致商业写真质感，皮肤细腻有光泽。造型：金属框墨镜架在头顶，双耳佩戴绿松石复古耳坠，面部带自然小雀斑，俏皮地抬头望向上方、微张嘴。画面四角散布暖色四角星闪光sparkle，宝丽来复古细边框（内黑边外白边）。整体明亮通透，Y2K千禧潮流氛围。
```

**变体2 prompt：**
```
将这张人物照片转换为Y2K潮流大头贴风格写真。1:1正方形构图，大头特写，头部居中，纯白色干净背景。严格保留原图人物的面部五官、脸型、神态和标志性帽子（保留帽子原有颜色与图案）。高清精致商业写真质感。造型：帽子上装饰满彩色珠串、星星别针、金属链条和彩色圆珠；脸上戴黑色窄框墨镜；开心大笑露齿，牙齿贴满闪亮水钻grillz。人物整体带白色描边cutout贴纸轮廓，像贴纸一样贴在白底上。Y2K千禧潮流、搞怪可爱氛围。
```

**变体3 prompt：**
```
将这张人物照片转换为Y2K潮流大头贴风格写真。1:1正方形构图，大头特写，头部居中，纯白色干净背景。严格保留原图人物的面部五官、脸型、神态和标志性帽子（保留帽子原有颜色与图案）。高清精致商业写真质感。造型：佩戴镭射银全息透明质感的头戴式耳机。画面周围散布银色立体四角星和彩虹小贴纸。整体加一个透明全息镭射质感的圆角方形边框。Y2K千禧未来感、可爱潮流氛围。
```

### 第四步：交付
- 3 张图全部生成后，逐张交付（每张图前用一句话说明造型）
- 使用 NotifyHuman 分别交付 3 张图片（多媒体产物每次只放 1 个附件）
- 说明已保留人物面部特征、做了哪些风格化处理
- 询问是否需要调整某个变体或更换配饰

## 注意事项
- **必须输出 3 张**，数量与参考组图一致，三个变体各一张，不可遗漏或合并
- **人物身份优先**：面部五官、脸型、神态必须与原图一致，只改造型、配饰、背景、画质
- **标志性服饰保留**：原图中的帽子/发饰等识别物必须保留其颜色和图案，只在其基础上加装饰
- **背景必须纯白**：不要保留原图的环境场景
- **比例固定 1:1**：无论原图什么比例，输出均为 2048×2048 方形
- 若原图不是人物正面照，尽量基于可见面部特征生成；面部严重遮挡时提示用户
- 参考图仅作风格引导，不要把参考图中他人的脸复制到结果中
- 若用户要求更多变体或不同配饰，可在保持核心风格（白底+大头特写+高清+Y2K配饰+星星贴纸）前提下扩展
