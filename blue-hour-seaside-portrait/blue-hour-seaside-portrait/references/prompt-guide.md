## 通用 prompt 模板

### 标准版（适用于大多数人物照片）
```
保持人物面部特征、五官和身份完全不变，将照片转换为蓝调时刻海边蕾丝头巾氛围感人像写真：人物头戴薄荷绿蕾丝头巾，头巾边缘有精致蕾丝花纹自然垂落肩侧，身穿同色系薄荷绿透视蕾丝连衣裙；蓬松大波浪长卷发，部分发丝被海风轻拂飘动；佩戴复古华丽金色垂坠耳环；自然清透妆容，粉色珊瑚色唇釉，淡淡腮红；背景为蓝调时刻的海边，灰蓝冷调天空与平静海面，远处山峦轮廓，浅景深背景虚化；柔和散射光，面部自然补光，眼神光自然；电影感低饱和调色，冷蓝灰背景与暖调通透肤色形成冷暖对比，薄荷绿为画面亮色点缀，金色饰品暖色高光；忧郁浪漫宁静的情绪氛围，中近景人像构图，胶片质感
```

### 加强电影感版
```
保持人物面部特征、五官和身份完全不变，强烈的电影感蓝调时刻海边人像：薄荷绿蕾丝头巾紧紧包裹头顶，蕾丝花纹精致通透，同色蕾丝长裙在海风中轻摆；湿润蓬松的大波浪卷发，发丝凌乱而有美感；复古金色吊灯式耳环在暗光中微微反光；面部一侧有柔和的侧光，明暗过渡细腻，眼神深邃；背景是深蓝色的海面和灰蓝色云层，远处海岸线模糊可见，空气中有薄雾感；青橙色调电影调色，暗部偏青蓝，肤色偏暖橙，高对比但不生硬；王家卫式情绪氛围，中近景特写，浅景深，颗粒感胶片画质
```

### 清新柔和版
```
保持人物面部特征、五官和身份完全不变，清新柔和的蓝调海边人像：浅薄荷绿蕾丝头巾轻盈覆盖头顶，蕾丝花纹细腻，搭配同色蕾丝上衣；自然蓬松的微卷长发，发丝柔顺有光泽；精致金色小花耳环；清透裸妆，自然粉色唇；背景为黄昏后的海边，淡蓝灰色天空和柔和海面，光线均匀柔和；低对比低饱和调色，整体偏冷但肤色通透粉嫩；宁静温柔的氛围，中近景构图，画面干净简洁
```

## 按变化分类的 prompt

### 不同耳环款式
- **吊灯式**：`佩戴复古金色吊灯式垂坠耳环，多层金属花丝工艺，精致华丽`
- **花朵式**：`佩戴金色花朵造型耳环，花瓣纹理细腻，复古宫廷感`
- **心形式**：`佩戴金色心形垂坠耳环，爱心轮廓配小珍珠，浪漫复古`
- **珍珠款**：`佩戴金色珍珠垂坠耳环，温润珍珠与金属光泽对比`

### 不同发色
- **深棕（标准）**：`深棕色蓬松大波浪长卷发`
- **红棕**：`红棕色蓬松大波浪长卷发，发丝在暗光中呈暖棕红色光泽`
- **黑色**：`自然黑色蓬松大波浪卷发，发丝有健康光泽`

### 不同表情/情绪
- **沉思内敛**：`表情沉静内敛，目光望向远方或镜头，若有所思`
- **微笑**：`自然浅笑，嘴角微微上扬，温柔浪漫`
- **冷感**：`表情清冷疏离，眼神淡漠，高级感`

### 不同背景变化
- **礁石海岸**：`深色礁石海岸，海浪轻拍礁石，浪花为背景增添动感`
- **沙滩**：`安静沙滩，沙色在暗光中偏深，海岸线延伸`
- **码头/防波堤**：`海边防波堤或码头，水泥/木质结构增添场景层次`

## 效果调节

| 用户反馈 | 调整方式 |
|---------|---------|
| "头巾不像/不自然" | 强调"蕾丝头巾紧密贴合头顶，边缘蕾丝花纹清晰可见，自然垂落"，可参考 assets 中头巾造型 |
| "颜色太绿了/太亮" | 将"薄荷绿"改为"浅薄荷绿/淡苹果绿"，降低饱和度描述 |
| "不够蓝调/像白天" | 加强"蓝调时刻""深蓝色天空""暗光环境""低照度" |
| "面部不像本人" | 在 prompt 开头加强"严格保持人物五官、脸型、面部特征完全一致"，确保用 image_edit 而非 image_gen |
| "太暗了看不清脸" | 加入"面部有柔和补光，面部清晰明亮，曝光准确" |
| "不够电影感" | 使用加强电影感版，加入"青橙色调""颗粒感""侧光""薄雾" |
| "想要更清新" | 使用清新柔和版，降低对比度和饱和度 |
| "背景不好看" | 指定具体背景类型（礁石/沙滩/码头），强调"浅景深虚化背景" |
| "耳环不对" | 从耳环款式列表中选择指定款式 |

## 常见问题与修正

### 问题：生成后人物面部变形/不像本人
- **修正**：在 prompt 开头强调"严格保持人物五官、脸型、面部特征和身份完全不变"
- 确保使用 `image_edit` 而非 `image_gen`
- 可尝试降低风格强度，保留更多原图面部信息

### 问题：蕾丝头巾没有出现或造型错误
- **修正**：在 prompt 中明确"薄荷绿蕾丝头巾（hood）覆盖头顶，不是发带或帽子"，描述头巾的形状和垂落方式
- 读取 assets 参考图确认头巾造型

### 问题：色调偏暖/不像蓝调时刻
- **修正**：强调"蓝调时刻（blue hour），日落后的冷调光线，天空和海面呈灰蓝色"，加入"色温偏冷""白平衡偏蓝"

### 问题：服装不是蕾丝裙
- **修正**：明确"薄荷绿色透视蕾丝面料连衣裙，可见蕾丝花纹和网纱质感"，不要只写"绿色裙子"

### 问题：图片比例不对
- **修正**：`width` 和 `height` 必须与原图一致，从用户图片元数据获取尺寸

### 问题：人物变成了全身照或远景
- **修正**：在 prompt 中强调"中近景人像构图，胸部以上或半身取景，人物占画面主体"
