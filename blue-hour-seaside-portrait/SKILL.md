# 蓝调时刻海边蕾丝头巾人像（Blue Hour Seaside Portrait）
将人物照片转换为蓝调时刻（黄昏后/黎明前）海边拍摄的氛围感人像写真：冷蓝灰调的海与天，薄荷绿蕾丝头巾与连衣裙，复古金色华丽耳环，蓬松大波浪卷发，柔和自然光，电影感低饱和调色，忧郁浪漫的情绪氛围。

## 风格核心特征
1. **场景与时间**：蓝调时刻（blue hour）的海边，天空呈灰蓝/冷青色调，云层柔和，远处有山峦或海岸线轮廓；海面平静有微波，礁石或沙滩作为前景
2. **光线**：柔和的环境散射光，无强烈直射阳光；面部有自然补光，明暗过渡柔和；整体偏暗但人物面部清晰可见；眼神光自然
3. **标志性造型——蕾丝头巾**：薄荷绿/浅苹果绿的蕾丝头巾（hood）覆盖头顶，头巾边缘有精致蕾丝花纹，自然垂落在肩侧；同色系蕾丝连衣裙或上衣，透视网纱质感，可见花纹
4. **发型**：蓬松的大波浪长卷发，深棕色或红棕色，发丝有光泽和空气感，部分发丝被海风轻拂飘动
5. **配饰**：复古华丽的金色耳环（吊灯式/花朵式/心形垂坠等款式），金属质感精致；可搭配细项链
6. **妆容**：自然清透底妆，粉色/珊瑚色唇釉，淡淡腮红，眉形自然，睫毛纤长
7. **色调与调色**：
   - 背景：低饱和冷蓝灰调，海与天统一在冷色系
   - 人物：肤色通透偏暖，与冷背景形成冷暖对比
   - 薄荷绿头巾/裙子作为画面中唯一的亮色点缀
   - 金色饰品提供暖色高光
   - 整体电影感/胶片感调色，暗部偏青蓝，高光柔和
8. **构图与景深**：中近景人像（胸部以上或半身），人物居中或微侧；浅景深背景虚化，突出人物；海与天空占画面上半部分
9. **情绪氛围**：忧郁、浪漫、宁静、若有所思、电影女主角感；表情自然内敛，可微笑或沉思

## 工作流程
### 第一步：分析用户图片
收到用户图片后，先观察：
- 人物的面部特征、发型、朝向（必须保持）
- 人物当前的服装和配饰
- 图片的光线方向
- 人物的表情和姿态

**必要时读取参考图**：如果对造型细节、色调或氛围不确定，用 `Read` 工具查看 `assets/` 目录下的参考图。参考图索引见本文档末尾。

### 第二步：生成风格化图片
使用 `image_edit` 工具，将用户图片作为参考图传入。详细 prompt 模板和参数见 [references/prompt-guide.md](references/prompt-guide.md)。

**基础 prompt 结构**：
```
保持人物面部特征、五官和身份完全不变，将照片转换为蓝调时刻海边蕾丝头巾氛围感人像写真：人物头戴薄荷绿蕾丝头巾，头巾边缘有精致蕾丝花纹垂落肩侧，身穿同色系薄荷绿透视蕾丝连衣裙；蓬松大波浪长卷发，部分发丝被海风轻拂；佩戴复古华丽金色垂坠耳环；自然妆容，粉色唇釉；背景为蓝调时刻的海边，灰蓝冷调天空与平静海面，远处山峦轮廓，浅景深虚化；柔和散射光，面部自然补光；电影感低饱和调色，冷蓝灰背景与暖调肤色形成对比，薄荷绿为画面亮色点缀；忧郁浪漫的情绪氛围，中近景人像构图
```

**关键参数**：
- `model_version`: `seedream_4.5`（默认）
- `image_reference_url_list`: 用户图片的 URL（必须）
- `width` / `height`: 保持原图比例
- `prompt`: 按上述结构，根据图片内容具体化

### 第三步：交付与迭代
- 生成后通过 `NotifyHuman` 交付图片
- 如果用户觉得头巾/服装不对，调整蕾丝头巾和服装的描述
- 如果色调偏了，强调"冷蓝灰调""低饱和""电影感"
- 如果面部不像，加强"保持人物面部特征、五官完全不变"
- 可多次生成让用户选择

## 注意事项
- **人物面部特征必须保持**，这是风格迁移的第一原则，不能改变五官和身份
- 蕾丝头巾是此风格的标志性元素，必须自然地戴在头上，边缘花纹清晰
- 背景必须是蓝调时刻的海边，不能是白天或黑夜
- 薄荷绿是核心点缀色，不要改成其他颜色（除非用户明确要求）
- 金色耳环要精致复古，不要现代简约款
- 整体氛围是忧郁浪漫，不要拍成明亮欢快的旅游照
- 保持中近景人像构图，不要变成全身照或大远景
- 如果原图有文字，保持文字清晰可读
